Problem: Search a list of names for one target name and report whether it was found.

Input:
- a list of names
- one target name
Output:
- "Found" or "Not found"
- or an error if the list is empty
Pseudocode:
START
    IF the list of names is empty THEN
        OUTPUT "Error: list is empty"
    ELSE
        SET result TO "Not found"
        FOR each name IN the list of names DO
            IF name equals target name THEN
                SET result TO "Found"
            END IF
        END FOR
        OUTPUT result
    END IF
END
