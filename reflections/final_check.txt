What a pull request asks teammates to do:
 
A pull request asks teammates to review the code changes I made on my separate branch. It invites them to discuss the work, catch any potential bugs, and approve the integration of my branch into the shared project.

Why branches and pull requests are used together: 

They are used together because a branch provides the isolated workspace to safely write the code, and a pull request provides the necessary formal review process to safely merge that code.
